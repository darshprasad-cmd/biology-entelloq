Learning tools: sources and boundaries

Return using the workspace's Back to section button. The new tools preserve the original Biology sections and saved learning history.

  • vtk.js renders the microscopy stack. The viewer supplies source attribution, channels and physical voxel spacing. The data is for education, not diagnosis.
  • Tellurium computes the curated enzyme reaction model. The workbench identifies units and assumptions. New simulations require the local companion service on 127.0.0.1:8932; the public static page does not secretly provide a remote compute service.
  • ts-fsrs schedules review from explicit recall ratings. Review timing is distinct from assessment scores or conceptual mastery.
  • Yjs preserves shared notebook edits. The notebook explains its implemented sharing mode; a hosted classroom service is not implied.
  • Transformers.js provides optional on-device semantic search of curated concepts. Model downloads occur only when you enable them; ordinary search stays available.
  • Excalidraw provides the editable scientific sketchbook in Solve, Reason and Labs. Scenes stay in this browser and can be exported as editable files or images. Drawing a pathway does not compute its behavior, and this integration does not create online collaboration rooms.
  • Manim Community renders the authored explanations in Learn. Playback starts only when requested; captions, a transcript and still alternatives accompany the video. These illustrations are not live computations or experimental recordings.

Saved work and portable use

Sketches, notes and review history remain local to the current browser origin. Export important work before clearing browser data. A separately copied HTML file has its own storage boundary. Optional online services and the local compute companion retain their stated requirements.

Companion and source files

Runtime setup, pinned dependencies, scientific checks and notices accompany learning-tools-source/biology/ in the source repository. The portable app carries its browser assets; it does not embed a Python installation.
