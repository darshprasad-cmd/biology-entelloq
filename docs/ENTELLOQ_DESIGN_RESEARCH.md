# Entelloq design research

Reviewed 2026-10-29. Evidence below is public official documentation and published research from the product authors. It is not a claim of authenticated live-product testing, copied assets or measured Entelloq learning outcomes. Adapt the principles to the existing engines and the accepted subject identities.

## Concrete interaction rules

The new user path is Discover → Launch → Manipulate → Understand → Save. Every step should have one clear next action and a route back. A guest can enter at any stage. Account or curriculum questions must not block a supported local experiment.

Search ranks authored metadata deterministically. Support normalized terms, scientific aliases and natural-language filler removal; describe limitations honestly. A rule-based query matcher is not semantic AI, and all-zero results should not be replaced with confident irrelevant matches. Subject changes preserve a visible destination and never load Quant, which is outside this task.

Scientific workspaces keep the viewport prominent, with a compact toolbar and collapsible controls/explanation. A control appears only if its engine supports the operation. Full experiment restore requires a known versioned state adapter; observation-only notes must say so. Saved means a confirmed successful write, not a button animation.

The search dialog should implement focus entry/trapping/return, Escape and a named close action. A combobox should expose expanded/selected state and supported arrow-key behavior. W3C's [dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) and [combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) patterns provide the authoritative reference; automated axe checks supplement manual keyboard review.

## Validation limits

Reference-product features are design evidence only. They do not establish that Entelloq is easy to use or scientifically validated. Compare actual local before/after screenshots and interaction journeys in Physics and Biology separately at desktop and mobile widths. Record accessible target names and observed behavior, not just source selectors. Human student sessions remain required for the 30-second first-interaction goal and learning-comprehension claims.
