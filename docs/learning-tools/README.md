# Learning tools inside Biology

The existing Biology sections now contain enzyme kinetics in Labs, microscopy in Explore, a retrieval queue in Solve and Me, notebooks in Reason and Labs, and concept search in Learn. Direct app links use `#labs/learning-kinetics`, `#explore/learning-volume`, `#solve/learning-review`, `#reason/learning-notebook` and `#learn/learning-search`.

The Tellurium companion runs a fixed enzyme mechanism with concentrations in micromolar and time in seconds. The workbench states its assumptions and companion status; the static site does not provide a remote solver. For local setup, follow [the companion instructions](../../learning-tools-source/biology/README.md). vtk.js renders a real CC0 fluorescence stack with source attribution, physical spacing and two labelled channels.

ts-fsrs schedules eight curated Biology concepts from explicit recall ratings. Yjs supports same-browser/site tabs and exported document merging. Concept search covers eight curated explanations, with keyword search by default and optional Transformers.js/MiniLM inference. It does not search the entire app, generate answers or provide online classroom rooms. The model downloads from Hugging Face after Enable.

Pinned source, notices, model/data provenance and scientific tests live under `learning-tools-source/`. Published files and SHA-256 manifests live under `assets/learning-tools/`. Run `python scripts/sync-learning-tools.py`, `python scripts/build-learning-tools.py` and `python scripts/build-single-file.py` after source changes; each supports `--check`. The portable package defers large assets, creates correctly typed worker/WASM URLs only on request, and releases them on cancellation or teardown. The semantic Worker deliberately retains its own browser API realm.
